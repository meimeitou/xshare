# 基金分析 Skill

## 何时使用

用户询问基金相关问题时激活，包括但不限于：

- 查询基金基本信息（类型、规模、基金经理）
- 分析基金绩效（收益率、回撤、夏普比率）
- 比较不同基金

## 工作流程

1. **确认标的**：获取基金代码（如 110011）
2. **基础信息** → `fund_info`
3. **绩效分析** → `fund_analysis`（可指定 1y/3y/5y 周期）
4. **输出格式**：
   - 基金基本信息（名称、类型、基金经理、规模）
   - 绩效指标（年化收益、最大回撤、夏普比率）
   - 风险提示

## 免责声明

> 基金过往业绩不预示未来表现，投资需根据自身风险承受能力审慎决策。
