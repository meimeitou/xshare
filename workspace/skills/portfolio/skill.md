# 持仓管理 Skill

## 何时使用

用户涉及个人持仓相关操作时激活：

- "我买了 1000 股紫金矿业，15 块买的"
- "我 18 块卖了 500 股紫金矿业"
- "我的持仓怎么样了"
- "我清仓了比亚迪"

## 工作流程

### 记录买入

1. 解析用户提到的股票 → `stock_resolve` 确认代码
2. 提取买入价格、数量、日期
3. 调用 `portfolio_update`（action=buy）

### 记录卖出

1. 确认标的和卖出价格、数量
2. 调用 `portfolio_update`（action=sell）
3. 系统自动校验卖出数量不超过持仓

### 查看持仓

1. 调用 `portfolio_summary` 获取持仓列表和已实现盈亏
2. 对每只持仓股调用 `stock_quote` 获取价格（非交易时段也应使用最近交易日数据）
3. 计算浮动盈亏（现价 × 数量 - 持仓成本）
4. 输出格式：
   - 表格展示：股票、持仓数量、成本价、现价、浮盈/浮亏金额、盈亏比例
   - 已实现盈亏（已卖出部分的盈亏）
   - 合计：总市值、总成本、总盈亏

### 删除记录

1. 确认用户要删除的标的
2. 调用 `portfolio_update`（action=delete）

## 注意事项

- 用户说"买了/卖了"但没给价格/数量时，主动追问
- 盈亏计算必须用工具返回的实时价格，不可编造
- 非交易时段说明"以最近交易日收盘价计算"
- 同一只股票可以多次买入不同价格，系统自动计算加权均价
